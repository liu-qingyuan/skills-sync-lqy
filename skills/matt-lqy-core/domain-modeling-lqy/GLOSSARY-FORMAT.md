# 领域术语表格式

新项目使用 `GLOSSARY.md`；旧项目按已指定的同一份文档写入，不因格式说明自动迁移。

```markdown
# {领域名称}

{用一两句话说明领域及范围。}

## Language

**Order**:
{定义它是什么，保持一两句话。}
_Avoid_: Purchase, transaction
```

- 同一概念选择一个规范名字，其它容易混淆的叫法可放 `_Avoid_`。
- 只记录真实领域概念，不复制通用编程词汇、代码、spec 或实现决策。
- 概念自然成组时才分组，否则平铺即可。
- 多领域项目由明确的 `GLOSSARY-MAP.md`（或未迁移的既有 map）索引各领域术语表；按当前主题只读取相关领域。
- 没有术语表时，在第一个概念明确后才创建；不要预先造空目录或多个文档。
