name: handoff-lqy
disable-model-invocation: true
description: 把当前对话压缩成交接文档，方便另一个 agent 继续。
---

编写一份总结当前对话的交接文档，以便新的 agent 可以继续工作。保存到用户操作系统的临时目录 - 而不是当前工作区。

在文档中包含“建议的技能”部分，其中建议 agent 应调用的 skill。

不要复制其他工件（PRD、计划、ADR、问题、提交、差异）中已捕获的内容。请改为通过路径或 URL 引用它们。

仅在新交接文档的展示副本中隐藏已确认的真实凭据值，不修改源日志、配置、fixture、业务数据或真实复现输入。保留必要结构与诊断标识；如果隐藏会阻碍继续工作，说明限制并向用户询问，不擅自清洗原件。

如果用户传递了参数，请将它们视为下一个会话将重点关注的内容的描述，并相应地调整文档。
