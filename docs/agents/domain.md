# 领域文档

本仓库使用单领域上下文：根 `GLOSSARY.md` 是唯一领域术语表，相关决策放在 `docs/adr/`。

开始相关工作前读取术语表和有关 ADR；文件不存在时安静地继续，不预先创建空目录。术语或难以逆转的决策真正明确时，由 `domain-modeling-lqy` 按需维护。

issue、spec、Ticket、测试和提案使用术语表定义的概念。实现细节不写入术语表；既有 ADR 冲突必须明确提出。

对其它已配置项目，优先遵守其领域文档 pointer；尚未迁移的 `CONTEXT.md` 继续作为同一份权威文档，不自动更名或双写。新项目默认 `GLOSSARY.md`。本仓库此次改名已经用户授权，不代表授权改名所有项目。
